1. Find the 2nd / Nth Highest Salary ⭐⭐⭐⭐⭐

Question:
You have an employee table containing employee_id, employee_name, department_id, and salary.

Write an SQL query to find the second-highest distinct salary from the employee table.

Follow-up:
How would you modify the query to find the Nth highest distinct salary, where N can be any given number?

2. Find Duplicate Records ⭐⭐⭐⭐⭐

Question:

Some employees may have accidentally registered using the same email address.

Write an SQL query to find all email addresses that appear more than once in the table.

Follow-up:
Write a query to retrieve the complete employee records associated with those duplicate email addresses.
